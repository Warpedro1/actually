# Requisitos

Requisitos funcionais (RF) e não funcionais (RNF) do sistema, com critério de aceite verificável. A coluna **Teste** aponta o teste automático que cobre o requisito (rodado por `pnpm test`; os de navegador por `pnpm --filter @actually/web test:e2e`). O teste `tests/acceptance/test/traceability.test.ts` falha se algum requisito ficar sem teste marcado com o seu ID (ex.: `[RF05]`).

Testes que exigem chaves de serviços (latência real, precisão real) rodam no eval quando as chaves existirem; o resto roda offline em CI.
